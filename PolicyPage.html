Privacy Policy for Chess AI Assistant

Last Updated: February 2024

Introduction

This privacy policy explains how Chess AI Assistant ("we", "our", or "the extension") handles user data. The extension is designed for educational purposes only.

Data Collection

Our extension collects minimal data necessary for its educational function:

  • Chess positions from your active Lichess.org games
  • User preferences and settings

Data Usage

The data collected is used solely for:

  • Analyzing chess positions for educational purposes
  • Providing strategic recommendations
  • Saving your preferences

Data Storage

All user preferences are stored locally in your browser using Chrome's storage API. Chess positions are processed in real-time and are not permanently stored.

Third-Party Services

The extension interacts with:

  • Lichess.org - for chess game integration
  • Nebius AI API - for chess position analysis

Data Protection

We implement security measures to protect your data:

  • Local storage of preferences
  • No collection of personal information
  • No sharing of data with third parties except as necessary for chess analysis

User Rights

You have the right to:

  • Disable the extension at any time
  • Clear local storage data through your browser
  • Use the extension without creating an account

Changes to Privacy Policy

We may update this privacy policy as needed. Significant changes will be notified through the extension's update notes.

Contact

For privacy concerns or questions, please create an issue on our GitHub repository.
